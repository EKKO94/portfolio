How I work now

I design in Figma, then build and review with AI agents, so what I design is what ships.

  1. 1

    Define the system in Figma

    Type, colour and patterns are set once, by hand, before any code.

  2. 2

    Hand it to Claude Code as rules

    Those guidelines become the design rules the agent builds against. Nothing drifts.

  3. 3

    Cross-review with Codex

    Claude builds and Codex reviews, then the other way round, until both agree.

  4. 4

    I review and send it back

    Accessibility and quality skills run first. I check the result, fix what is wrong and repeat.
